# Standards and Authorities

- Executive Order 14412, *Securing the Nation Against Advanced Cryptographic Attacks*:
  https://www.whitehouse.gov/presidential-actions/2026/06/securing-the-nation-against-advanced-cryptographic-attacks/
- NIST FIPS 203 (ML-KEM), FIPS 204 (ML-DSA), and FIPS 205 (SLH-DSA):
  https://csrc.nist.gov/projects/post-quantum-cryptography/
- NIST NCCoE Migration to Post-Quantum Cryptography:
  https://www.nccoe.nist.gov/applied-cryptography/migration-to-pqc
- NIST Crypto Agility publications:
  https://csrc.nist.gov/Projects/crypto-agility/publications
- CycloneDX 1.7 specification:
  https://github.com/CycloneDX/specification

Standards identify algorithms and migration obligations. They do not establish
that a particular implementation or module is FIPS validated; that requires
CMVP evidence for the exact module, version, platform, and operating mode.
